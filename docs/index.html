Engine Architecture & Features

Engineered for high-fidelity meme generation, multi-platform deployment, and robust async rendering.

Neural Background Removal

Uses ONNX-accelerated rembg with the u2net neural network. Automatically isolates portrait subjects, solidifies semitransparent alpha boundaries, and produces pitch-black silhouettes.

Dual-Phase Timeline Video

Composes 1920x1080 24fps MP4 with H.264 & AAC: Stage 1 (0.0s to 3.3s) teaser silhouette over rotating rayburst, followed by Stage 2 (3.3s to 6.77s) character reveal and fanfare.

Authentic 90s Typography

Renders custom Pokémon Solid, Hollow, and Arcade fonts with dual-pass stroke rendering, dynamic badge sizing, and RFC 5987 Unicode filename sanitation for international characters.

Tauri 2 Native Desktop App

Distributed as a lightweight, cross-platform native application for macOS, Windows, and Linux using Tauri 2 and Rust, alongside the React 18 TypeScript Progressive Web App.

Async Queue & Auto-Purge

Asynchronous job queue (`/api/jobs`) with non-blocking HTTP polling, memory state management, and an automated background disk garbage collection worker that cleans expired artifacts.

Procedural Asset Fallback

Zero-missing-asset failures: procedural rayburst canvas synthesis with Pillow and NumPy, plus 8-bit retro chiptune audio generation via SciPy if local sound assets are omitted.

How It Works

From portrait photo to completed 1080p reveal video in four automated steps.

01

Input Validation

The client submits a portrait image with selected theme and name. The backend verifies MIME type, enforces memory quotas, and assigns a persistent job identifier.

02

Neural Segmentation

The u2net neural network identifies foreground contours, generating an alpha transparency mask with boundary edge anti-aliasing.

03

Silhouette & Typography

A solid jet-black mask (#000000) is created for Stage 1. Custom Pokémon fonts are dynamically rendered with dual-stroke outlines for Stage 2.

04

MoviePy Assembly

MoviePy composes rotating rayburst background, silhouette, character reveal, and audio fanfare into a 6.77s 1080p 24fps MP4 stream.

Developer Quick Start

Run the application locally in seconds using Docker or Make commands.

bash — docker-compose 
# Clone repository
git clone https://github.com/AtaCanYmc/who-is-that-pykemon.git
cd who-is-that-pykemon

# Configure environment
cp .env.example .env

# Build and start services
docker compose up --build -d

# Open web app: http://localhost:3000
# OpenAPI Swagger docs: http://localhost:8000/docs
